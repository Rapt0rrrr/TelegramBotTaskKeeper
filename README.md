Telegram Task Keeper Bot

Мой проект на Python — умный Telegram-бот для управления задачами и напоминаниями.

Стек технологий:
1) Python 3.14
2) Aiogram 3.x (асинхронная работа с Telegram Bot API)
3) SQLite3 (реляционная база данных для хранения задач, пользователей и напоминаний)
4) Asyncio (для работы фонового воркера напоминаний)
5) FSM (Машина состояний для пошагового диалога с пользователем)

Функционал:
1) Онбординг: приветственный экран для новых пользователей (сохраняется в БД).
2) Задачи: добавление, просмотр одним сообщением и удаление задач.
3) Защита от ошибок: если ввести неверный номер задачи для удаления, бот просит ввести число заново.
4) Напоминания: можно поставить напоминание на любую дату и время (выбрав задачу из списка или написав свой текст).
5) Фоновый процесс: бот проверяет базу данных каждые 30 секунд и отправляет уведомления точно в срок.
6) Отмена действий: в любой момент ввода можно нажать «Отмена» и вернуться в главное меню.
